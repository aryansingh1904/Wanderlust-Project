# Wanderlust 🌍

Wanderlust is a full-stack travel accommodation platform inspired by Airbnb. Users can explore and discover unique places to stay, view detailed listings, create their own properties, and manage their listings through an intuitive web interface.

### ✨ Features

* 🔐 User authentication and authorization
* 🏡 Create, edit, and delete property listings
* 🔎 Browse and explore available accommodations
* 📍 Location-based property information
* ⭐ Reviews and ratings
* 🖼️ Image uploads for listings
* 📱 Responsive and user-friendly design
* 🛡️ Secure access and validation

### 🛠️ Tech Stack

* **Frontend:** HTML, CSS, JavaScript, Bootstrap
* **Backend:** Node.js, Express.js
* **Database:** MongoDB
* **Authentication:** Passport.js
* **Templating:** EJS
* **Deployment:** Render

Wanderlust was built to provide a practical, real-world experience with full-stack web development, database management, authentication, RESTful APIs, and responsive UI design.
